# Third-party skills I use

These are **not part of this repo** — they're skills authored by others that I install alongside my own. Listed here so the set is documented in one place. Install each from its own source (many are on the [`bunx skills`](https://www.skills.sh/) registry — try `bunx skills find <keyword>`).

| Skill | What it does | Upstream |
|-------|--------------|----------|
| `adhd` | Parallel divergent ideation: spawns N isolated branches under different cognitive frames, scores, clusters, prunes, deepens the survivors. | external |
| `brag` | Turns the current project's website into a short, shareable launch video. | [Hyperframes](https://hyperframes.dev) |
| `emil-design-eng` | Encodes Emil Kowalski's philosophy on UI polish, component design, and animation decisions. | based on [Emil Kowalski](https://emilkowal.ski) |
| `generative-art` | Generative / creative-coding art: grids, Perlin/flow fields, particle systems, image-to-ASCII, with Tweakpane controls. | built on [canvas-sketch](https://github.com/mattdesl/canvas-sketch) (Matt DesLauriers) |
| `higgsfield-generate` | Generate images/videos via Higgsfield AI (GPT Image 2, Seedance, Nano Banana, Marketing Studio). | [Higgsfield AI](https://higgsfield.ai) |
| `higgsfield-marketplace-cards` | Marketplace product image cards: compliant main image, secondary images, A+ modules. | [Higgsfield AI](https://higgsfield.ai) |
| `higgsfield-product-photoshoot` | Brand-quality product photography (studio, lifestyle, ad creative, virtual try-on). | [Higgsfield AI](https://higgsfield.ai) |
| `higgsfield-soul-id` | Train a Soul Character (personalized face model) for identity-faithful generation. | [Higgsfield AI](https://higgsfield.ai) |
| `humanizer` | De-AI writing: detects and rewrites LLM-tell patterns for natural, human-sounding text. | external |
| `impeccable` | Frontend interface design/review: hierarchy, accessibility, typography, motion, tokens, live browser iteration. | external |
| `interview-coach` | High-rigor interview prep: transcript analysis, practice drills, storybank, performance tracking. | external |
| `teach` | Teach a new skill or concept within the current workspace. | external |

> `al-cli` (Arctic Leaf Teamwork CLI) is an internal tool and is intentionally not listed or published here.

Where **upstream** says "external", I use the skill locally but haven't pinned its canonical source — fill in when confirmed.
